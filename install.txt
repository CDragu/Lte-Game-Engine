To make and install the engine type:

    cd src
    make
    make install

To compile the game:

    cd game
    make

You only need the engine source code when changing the engine. Otherwise, a
precompiled version is available in the `libs/` folder.

If the toolchain reports conflicting `psptypes`, copy
`pspsdk/include/psptypes.h` to the PSPSDK include folder.
